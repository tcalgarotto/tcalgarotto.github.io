# Thales Calgarotto

Portfólio estático publicado em https://tcalgarotto.github.io/.

HTML, CSS e JavaScript, sem etapa de build. Português e inglês, temas claro e escuro, filtros de projetos e exploração interativa da arquitetura do JustOS. Preferências ficam apenas no navegador; não há analytics, formulários ou cookies de rastreamento.

## Preview local

```sh
python3 -m http.server 8766 --bind 127.0.0.1
```

Abra http://127.0.0.1:8766/.

## Conteúdo

- Projetos: repositórios públicos `tcalgarotto/Lex`, `tcalgarotto/loop-master` e `tcalgarotto/telemed`.
- Certificações: credenciais públicas do Coursera fornecidas pelo titular.
- Ilustração de capa: imagem original gerada para este portfólio, sem representar um produto real.
- Fontes: Space Grotesk e IBM Plex Mono, hospedadas localmente; licenças em `assets/licenses/`.
- Ícones: Phosphor Icons; licença em `assets/licenses/`.
- Logos das instituições: imagens oficiais disponibilizadas nas páginas das credenciais do Coursera. Identificam os emissores das formações; não indicam vínculo empregatício ou patrocínio.

Para alterar conteúdo traduzido, atualize `index.html` e os textos em `app.js`. O site continua legível e navegável sem JavaScript.
